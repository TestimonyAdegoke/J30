# J30 — Thirty, for Joyce

A private, interactive 30th birthday experience for Joyce.

## What is included

- Cinematic birthday entrance
- Joyce photo experience
- 30 reasons I love you
- "Open when..." letters
- Wishes for her thirties
- 30 Years of Becoming
- Birthday artwork
- Ambient audio option
- Confetti finale and hidden Easter egg

The entire experience is packaged into `index.html`, including its visual assets, so the repository can be deployed as a zero-build static site.

## Live

https://joyce-thirty.vercel.app

## Deploy

Import this repository into Vercel as a static project. No build command is required.
